# PRINT

![BASICStudio](https://img.shields.io/badge/BASICStudio-supported-brightgreen) ![BASICShell](https://img.shields.io/badge/BASICShell-supported-brightgreen)

Displays values in the console. Multiple expressions separated by commas are printed with spaces between them in the current implementation.

```basic
print "HELLO"
print "TOTAL =", 10 + 5
name$ = "AIBASIC"
print name$
```
