# FILES Command and Statement

![BASICStudio](https://img.shields.io/badge/BASICStudio-supported-brightgreen) ![BASICShell](https://img.shields.io/badge/BASICShell-supported-brightgreen)

Lists the visible files in the current working directory, similar to `ls`. It can be used directly at the prompt or as a program statement.

```basic
files
```
