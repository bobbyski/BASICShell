# RUN

![BASICStudio](https://img.shields.io/badge/BASICStudio-supported-brightgreen) ![BASICShell](https://img.shields.io/badge/BASICShell-supported-brightgreen)

Runs the current program. In BASICStudio, `RUN` uses the current editor contents. In BASICShell, `RUN` uses the current loaded or typed program.

```basic
10 print "HELLO"
20 end
run
```
