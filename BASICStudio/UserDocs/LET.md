# LET and Assignment

![BASICStudio](https://img.shields.io/badge/BASICStudio-supported-brightgreen) ![BASICShell](https://img.shields.io/badge/BASICShell-supported-brightgreen)

Assigns a value to a variable. `LET` is optional, so plain assignment works too. Variables are case-insensitive, while string variables end with `$`.

```basic
let x = 42
y = x + 8
name$ = "AIBASIC"
print y, name$
```
