# CHR$

![BASICStudio](https://img.shields.io/badge/BASICStudio-supported-brightgreen) ![BASICShell](https://img.shields.io/badge/BASICShell-supported-brightgreen)

Returns a one-character string for a numeric code. `CHR$(0)` creates a NUL-containing data-backed string; display output strips the NUL.

```basic
print "A"; chr$(0); "B"
```
